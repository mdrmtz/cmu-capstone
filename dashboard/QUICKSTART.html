Data Files 📁

The dashboards automatically load data from these JSON files (relative to the dashboard folder):

../results/results_summary.json (Main dashboard) ../results/audit.json (Main dashboard) ../benchmark_cases.json (Benchmark dashboard)

💡 Tip: If your data is in different locations, update the paths in the HTML files (search for RESULTS_SUMMARY_PATH, AUDIT_PATH, or BENCHMARK_PATH)

Pro Tips 💡

  • Dark Mode: Theme preference is saved automatically - switch once, it remembers forever
  • Search Anywhere: In benchmark cases, search works across all fields (ID, page, rule, fix text, etc.)
  • Expand for Details: Click the + button to see complete violation details and ground truth fix
  • Combine Filters: Use rule + page filters together to find specific combinations
  • Mobile Friendly: All features work on phones - table automatically becomes cards
  • WCAG Links: Click WCAG references to jump to W3C official pages
  • No Install Needed: Just open the HTML file - works offline too!

Troubleshooting 🔧

Dashboard says "Failed to load data"?

The JSON files are not in the expected locations. Make sure:

  • Files exist in ../results/ and ../ directories
  • File names match exactly (case-sensitive)
  • You're opening HTML from a file (file:// URLs work locally)
  • Check browser console (F12) for specific error messages
