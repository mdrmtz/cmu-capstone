**The A11y Fixer** is an autonomous, multi-agent software remediation system engineered to eliminate WCAG 2.2 AA technical debt in Angular codebases. It inspects live browser accessibility trees, traces violations to static source files, applies AST-level code patches, and delivers verified Pull Requests — without human intervention.

## System Architecture

The A11y Fixer uses a three-agent sequential pipeline governed by LangGraph:

| Agent | Role | Key Output |
|---|---|---|
| **Compliance Planner** | Retrieves authoritative WCAG clauses via Hybrid RAG | Structured compliance manifest |
| **Codebase Compiler** | Applies Tree-of-Thought AST patches (k=3 branches) | Candidate code diffs on isolated Git branches |
| **QA Critic** | Compiles, audits, and scores each patch (0–20 rubric) | Approve PR or trigger backtrack |

## Key Technical Decisions

- **Hybrid RAG** over naive vector search — deterministic LLM Wiki for known `axe-core` error codes, MMR-reranked semantic search for exploratory queries
- **Tree-of-Thought DFS** over linear Chain-of-Thought — handles combinatorial constraint complexity and enables safe backtracking without state pollution
- **LangGraph** over loose swarm orchestration — full auditability of every state transition for developer-reviewable Pull Requests
- **Git-backed transactional sandbox** — each ToT branch runs in a pristine workspace (`git checkout -f && git clean -fd`) to prevent state fragmentation
